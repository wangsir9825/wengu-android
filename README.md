# 温故

一个把生活和学习经验放进手机壁纸的 Android 小工具。将经验精简成一句话，让过去的总结多几次被看见和回想的机会。

- 平台：Android
- 制作方式：借助 Codex 开发
- [作品介绍与制作记录](https://www.zhutufang.cn/articles/wengu-experience-wallpaper/)
- [筑途坊 · 我的作品](https://www.zhutufang.cn/works/)

## 当前状态

此仓库先建立项目介绍和版本发布结构。首个公开 APK、可公开源码及构建说明将在整理完成后发布。

## 下载与历史版本

正式版通过本仓库 [Releases](https://github.com/wangsir9825/wengu-android/releases) 发布，同时保留百度网盘备份。发布后，网站作品页会提供下载地址。

每个版本包含：

- 对应版本的 APK；
- 更新说明及已知问题；
- 安装包的 SHA-256 校验值；
- 与源码对应的 Git 标签。

## 源码与构建

源码上传后补充构建环境、依赖、构建命令和目录说明。当前尚未提供构建说明或开源许可证。

## 反馈

使用中的问题或功能建议可以在本仓库 Issues 中提出。请描述设备型号、Android 版本、应用版本和复现步骤；提交截图前请隐藏个人信息。
